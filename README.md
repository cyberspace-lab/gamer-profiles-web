# Herní Typologie – CyberspaceLab

Website with information about gamer typologies and profiles, with the option to take your own test. Built with [Astro](https://astro.build/).

## Commands

| Command           | Action                                  |
| :---------------- | :-------------------------------------- |
| `npm install`     | Installs dependencies                   |
| `npm run dev`     | Starts local dev server                 |
| `npm run build`   | Builds the production site to `./dist/` |
| `npm run preview` | Previews the build locally              |
